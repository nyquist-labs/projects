PCB trace width (IPC-2221)

Minimum trace width for a current and temperature rise, with resistance and loss.

IPC-2221 is a curve fit to old measurements; IPC-2152 (not free) refines it. Inner-layer values here are the conservative 2221 rule.

Part of Nyquist Labs by Anna Lin — the calculation code (calc.js) is unit-tested against independent Python references; see this project's README.
