Nyquist Labs

Created and maintained by Anna Lin · an independent project, not affiliated with any company of a similar name

Electrical-engineering projects built one way: predict the answer from theory, measure it with an independent simulation, a hardware-description-language simulator or a public real-world dataset, compare the two numbers, and explain any disagreement — including the predictions that turned out wrong.

Interactive browser tools
How these projects were made. The code, simulations and write-ups in this repository were produced with the help of an AI coding assistant. Every number in a results table is computed by code in the repository and can be regenerated with python run_all.py. If you reuse this work — for coursework, applications or a portfolio — say so, describe your own contribution truthfully, and do not present it as solely your own.
Each card links to a project folder containing project.py, a README with the prediction-versus-measurement table and discussion, figures, and data. Datasets are credited in each README and in the top-level README.
